# Zombie Airship Pack

Packwiz metadata for a Minecraft 1.20.1 Forge modpack.

- Forge: 47.4.29
- Mod metadata files: 307

This repository tracks Packwiz metadata only: `pack.toml`, `index.toml`, and the files in `mods/`. Mod JARs are excluded from Git. The mod definitions were matched to their fixed CurseForge project and file IDs.

## Working with the pack

After installing Packwiz, run these commands from the repository root:

```powershell
packwiz refresh
packwiz curseforge export
```

Review any proposed version changes before using `packwiz update`.
